## Features

- **Character rigging templates** – ready‑to‑animate puppet limbs with inverse kinematics.
- **Sprite sheet libraries** – over 100 pre‑drawn game sprites (platformer, top‑down, etc.).
- **Sound effect packs** – royalty‑free SFX for games and interactive projects.
- **ActionScript 3.0 code snippets** – keyboard/mouse input, collision detection, and score systems.
- **HTML5 Canvas presets** – responsive export settings for web and mobile.
- **Timeline animation examples** – walk cycles, particle effects, and cinematic transitions.
- **Custom easing curves** – pre‑defined ease‑in/out profiles for organic motion.
- **Project structure templates** – organised folders for assets, scripts, and scenes.
- **Export presets** – optimised for GIF, video, and SWF formats.
- **Beginner’s tutorial** – step‑by‑step creation of a simple interactive animation.

## Requirements

- Windows 10/11 or macOS
- Adobe Animate (CC or later) – trial or licensed version
- Basic familiarity with timeline and symbols

## Usage

1. Extract files to your project directory.
2. Open Adobe Animate and create a new project.
3. Import the templates via `File > Import > Open External Library`.
4. Drag sprites from the library to the stage.
5. Apply scripts to frames or buttons using the Actions panel.
6. Adjust easing curves in the Motion Editor.
7. Export using the provided presets.
